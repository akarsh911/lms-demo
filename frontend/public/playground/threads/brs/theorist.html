Reconciliation and errors

A firm's own cash book and its bank's pass book almost never show the same balance on the same day — not because either book is wrong, but because some entries reach one book before the other. Set the reconciling items and watch the model derive one balance from the other, in either direction. Then, on the second tab, inject one of the five textbook kinds of error into a small ledger and see for yourself which ones the trial balance catches — and which ones slip through it completely.
