Tracing a program

A computer runs a program one statement at a time. Pick a small Python program — a loop that adds up numbers, a function that calls itself, or a function that quietly shadows a variable outside it (CBSE Class 11 Computer Science: flow of control) — and step through it. Every variable, every call stack frame and every printed line comes from a real little interpreter running your program, not a recording. On the second tab, push and pop values from a stack built from a Python list until it runs out, and watch an exception get raised, caught, and cleaned up by a finally block (Class 12: functions, scope, exception handling, and a stack implemented with a list).
